# {{$frontmatter.order}} {{ $frontmatter.title }}

Mic-E 消息标识符是一个 3 位代码（消息位 A、B 和 C），指定 7 种标准 Mic-E 消息代码之一、7 种自定义 Mic-E 消息代码之一，或一个紧急消息代码。

| 消息位 A/B/C | 标准 Mic-E 消息类型 | 自定义 Mic-E 消息类型 |
| --- | --- | --- |
| 1 1 1 | M0：离线 | C0：自定义-0 |
| 1 1 0 | M1：在途中 | C1：自定义-1 |
| 1 0 1 | M2：在服务中 | C2：自定义-2 |
| 1 0 0 | M3：返回中 | C3：自定义-3 |
| 0 1 1 | M4：已承诺 | C4：自定义-4 |
| 0 1 0 | M5：特殊 | C5：自定义-5 |
| 0 0 1 | M6：优先 | C6：自定义-6 |
| 0 0 0 | 紧急 | 紧急 |

标准消息和紧急消息对所有 APRS 电台具有相同的含义。自定义消息可以被赋予任意含义。

注意：对自定义消息的支持是可选的。原始 Mic-E 单元不支持自定义消息。

注意：如果 A/B/C 消息标识符位包含标准 1 和自定义 1 的混合，则消息类型为"未知"。

消息类型编码的一些示例：

| 前 3 个目的地址字节 | 消息标识符位 A/B/C | 消息类型 |
| --- | --- | --- |
| `S32` | 标准 1 / 0 / 0 | 标准 M3：返回中 |
| `F2D` | 自定义 1 / 0 / 自定义 1 | 自定义 C2：自定义-2 |
| `234` | 0 / 0 / 0 | 紧急 |
