# {{$frontmatter.order}} {{ $frontmatter.title }}

下表显示了目的地址字段前 6 个字节的编码，涵盖了纬度数字、3 位 Mic-E 消息标识符（A/B/C）、纬度/经度指示器和经度偏移的所有组合。

该编码支持位置模糊度。

表中显示的 ASCII 字符在传输前左移了一位。

**Mic-E 目的地址字段编码（字节 1–6）**

| ASCII 字符 | 纬度数字 | 消息 A/B/C | 南/北 | 经度偏移 | 西/东 |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 0     | 0     | 0          | 南 | +0   | 东  |
| 1     | 1     | 0          | 南 | +0   | 东  |
| 2     | 2     | 0          | 南 | +0   | 东  |
| 3     | 3     | 0          | 南 | +0   | 东  |
| 4     | 4     | 0          | 南 | +0   | 东  |
| 5     | 5     | 0          | 南 | +0   | 东  |
| 6     | 6     | 0          | 南 | +0   | 东  |
| 7     | 7     | 0          | 南 | +0   | 东  |
| 8     | 8     | 0          | 南 | +0   | 东  |
| 9     | 9     | 0          | 南 | +0   | 东  |
| A     | 0     | 1（自定义） | —     | —    | —     |
| B     | 1     | 1（自定义） | —     | —    | —     |
| C     | 2     | 1（自定义） | —     | —    | —     |
| D     | 3     | 1（自定义） | —     | —    | —     |
| E     | 4     | 1（自定义） | —     | —    | —     |

**注意：** ASCII 字符 `A`–`K` 不用于地址字节 4–6。

例如，对于一个位于北纬 33 度 25.64 分钟的电台，在西半球，经度偏移为 +0 度，发送标准消息标识符位 1/0/0，目的地址字段前 6 个字节的编码如下：

| 目的地址字节 | 1 | 2 | 3 | 4 | 5 | 6 |

| 纬度数字          | 3 | 3 | 2 | 5 | 6 | 4 |
| 消息位 A = 1（标准） | 1 |   |   |   |   |   |
| 消息位 B = 0       |   | 0 |   |   |   |   |
| 消息位 C = 0       |   |   | 0 |   |   |   |
| 南/北指示器           |   |   |   | 北 |   |   |
| 经度偏移             |   |   |   |   | +0 |   |
| 西/东指示器           |   |   |   |   |   | 西 |
| 目的地址（ASCII 字符） | S | 3 | 2 | U | 6 | T |
