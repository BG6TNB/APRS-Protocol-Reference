# {{$frontmatter.order}} {{ $frontmatter.title }}

作为遥测数据的替代方案，数据包可以包含 Mic-E 状态文本。状态文本可以是适合放入信息字段其余部分的任何长度。

Mic-E 状态文本不能以 `‘` 或 `0x1d` 开头，否则会与遥测数据混淆。

可以在 Mic-E 状态文本字段中包含标准 APRS 格式的位置。合适的位置将使 APRS 显示软件覆盖 Mic-E 编码的任何位置数据。这在使用没有 GPS 接收器的 Mic-E 时很有用。

注意：Kenwood 电台会在状态文本字符串的开头自动插入一个特殊类型代码（即信息字段的第 10 个字符）：

| 电台 | 类型代码 |
| --- | --- |
| Kenwood TH-D7 | `>` |
| Kenwood TM-D700 | `]` |

这些字符不应与出现在报告开头的 APRS 数据类型标识符混淆。

预计其他 Mic-E 兼容设备将来会被分配各自的类型代码。

注意：当 Kenwood 电台接收状态时，它们只能显示少量文本字符：

| 电台 | 字符限制 |
| --- | --- |
| Kenwood TH-D7 | 20 个字符 |
| Kenwood TM-D700 | 28 个字符 |

注意：Kenwood TM-D700 电台使用 `'`（撇号）代替 `‘`（重音符）APRS 数据类型标识符来表示当前 GPS 数据。检测这种情况的建议方法是检查信息字段的第一个和第 10 个字符；如果它们分别为 `'` 和 `]`，则数据包几乎肯定来自 TM-D700。
