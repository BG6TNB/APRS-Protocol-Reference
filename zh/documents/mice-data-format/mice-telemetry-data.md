# {{$frontmatter.order}} {{ $frontmatter.title }}

信息字段可以可选地包含 Mic-E 遥测数据值或 Mic-E 状态文本。

如果符号表标识符后面的字节是遥测标志字符之一（`‘` 或 `0x1d`），则后面为遥测数据：

可选的 Mic-E 遥测数据

| 遥测标志 | 遥测数据通道 |        |        |        |        |
| ---            | ---                     | ---    | ---    | ---    | ---    |
| F              | 通道 1                    | 通道 2   | 通道 3   | 通道 4   | 通道 5   |
| 字节:         | 1                       | 1/2    | 1/2    | 1/2    | 1/2    |

遥测标志 F 为以下之一：

| F | 含义 |
| --- | --- |
| `‘` | 后面有 2 个可打印的十六进制遥测值（通道 1 和 3）。 |
| `'` | 后面有 5 个可打印的十六进制遥测值。 |
| `0x1d` | 后面有 5 个二进制遥测值（仅 Rev. 0 测试版单元）。 |

如果 F 为 `‘` 或 `'`，每个通道需要 2 个字节，包含一个 2 位可打印的十六进制表示，值范围为 0–255。例如，254 表示为 `FE`。

如果 F 为 `0x1d`，每个通道需要一个字节，包含一个 8 位二进制值。

例如，如果遥测数据为 `'7200007100`，`'` 表示后面有 5 个字节的遥测数据，以十六进制编码：

| 通道 | 十六进制 | 十进制 |
| --- | --- | --- |
| 1 | 0x72 | 114 |
| 2 | 0x00 | 0 |
| 3 | 0x00 | 0 |
| 4 | 0x71 | 113 |
| 5 | 0x00 | 0 |
