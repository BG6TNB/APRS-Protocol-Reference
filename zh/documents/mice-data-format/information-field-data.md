# {{$frontmatter.order}} {{ $frontmatter.title }}

信息字段的前 9 个字节包含 APRS 数据类型标识符、经度、速度、航向和符号数据。

APRS 数据类型标识符为以下之一：

| 值 | 含义 |
| --- | --- |
| `‘` | 当前 GPS 数据（但不用于 Kenwood TM-D700 电台）。 |
| `'` | 旧 GPS 数据（或 Kenwood TM-D700 电台中的当前 GPS 数据）。 |
| `0x1c` | 当前 GPS 数据（仅 Rev. 0 测试版单元）。 |
| `0x1d` | 旧 GPS 数据（仅 Rev. 0 测试版单元）。 |

**重要提示：** 如下文详细说明，信息字段中的某些字节是非打印 ASCII 字符。在某些情况下（如 TNC 设置不正确或使用了不合适的软件），这些非打印字符中的一些可能会被丢弃，使信息字段看起来比实际短。这将导致错误的解码。（特别是，如果信息字段看起来少于 9 字节长，则必须忽略该数据包）。
