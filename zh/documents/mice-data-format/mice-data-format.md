在 Mic-E 数据格式中，电台的位置、航向、速度和显示符号，以及 APRS digipeater 路径和 Mic-E 消息代码，被打包到 AX.25 目的地址字段和信息字段中。

信息字段还可以可选地包含 Mic-E 遥测数据或 Mic-E 状态。Mic-E 状态可以包含电台的 Maidenhead 定位器和海拔高度。

Mic-E 数据包可以非常短。在最小配置下，Digipeater 地址字段中无呼号，且无可选遥测数据或 Mic-E 状态文本，一个完整的 Mic-E 数据包仅 25 字节长（不包括 FCS 和标志位）。

Mic-E 数据格式不仅用于麦克风编码器单元，还用于 PIC 编码器以及 Kenwood TH-D7 和 TM-D700 电台。

## Mic-E 数据载荷

Mic-E 数据格式允许在非常短的数据包中携带大量数据。数据被分配在标准 AX.25 UI 帧的目的地址字段和信息字段之间。

**目的地址字段** — 7 字节的目的地址字段包含以下编码信息：

- 6 位纬度数字。
- 一个 3 位 Mic-E 消息标识符，指定 7 种标准 Mic-E 消息代码之一、7 种自定义消息代码之一或紧急消息代码。
- 南/北和西/东指示器。
- 经度偏移指示器。
- 通用 APRS digipeater 路径代码。

尽管目的地址看起来非常不传统，但它仍然是有效的 AX.25 地址，仅由可打印的 7 位 ASCII 值组成（左移一位）——有关标准 AX.25 地址格式的完整信息，请参阅 *业余分组无线电链路层协议* 规范。

**信息字段** — 此字段包含以下数据：

- 编码后的经度。
- 编码后的航向和速度。
- 显示符号代码和符号表标识符。
- 一个可选字段，包含 Mic-E 遥测数据或 Mic-E 状态文本字符串。状态字符串可以包含纯文本、Maidenhead 定位器或电台的海拔高度。
