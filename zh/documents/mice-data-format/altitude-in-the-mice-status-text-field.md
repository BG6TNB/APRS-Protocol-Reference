Mic-E 状态文本字段可以包含电台的海拔高度。海拔高度以 `xxx}` 的形式表示，其中 `xxx` 相对于平均海平面以下 10 公里（最深的海洋）以 91 为基数的米数。

例如，计算 200 英尺海拔高度的 `xxx` 字符：

```
200 英尺 = 61 米 = 相对于基准面 10061 米
10061 / 91^2 = 1 , 余数 1780
1780 / 91 = 19 , 余数 51
```

将每个高亮值加上 33，得到 ASCII 码 34、52 和 84，对应 `xxx`。

因此 4 字符的海拔高度字符串为 `"4T}`

一些示例：

```
"4T}
>"4T}
]"4T}
```
