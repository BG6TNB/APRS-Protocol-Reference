# {{$frontmatter.order}} {{ $frontmatter.title }}

不符合本文档描述的任何格式的数据包被假定为非 APRS 信标。程序可以决定处理或忽略这些数据包，但必须能够在不产生不良影响的情况下处理它们。

APRS 程序可以将此类数据包视为 APRS 状态报告。这使得 APRS 能够捕获发送到典型信标地址的任何 UI 数据包作为状态消息。典型的 TNC ID 数据包属于此类。

一旦从某个电台接收到正确的状态报告（带有 APRS 数据类型标识符 `>`），它将不会被来自该电台的其他非 APRS 数据包覆盖。
