# {{$frontmatter.order}} {{ $frontmatter.title }}

为了表示数据包包含无效数据或不符合任何标准 APRS 格式的测试数据，使用 `,` 数据类型标识符。

例如，如果 Mic-E 单元检测到接收到的 GPS 语句无效，它将生成这样的数据包。

## 无效数据 / 测试数据格式

| 字段 | 描述 |
|-------|-------------|
| `,`   | 数据类型标识符 |
| ...   | 无效数据或测试数据 |

**字节数：** 1 n

### 示例
```
,191146,V,4214.2466,N,07303.5181,W,417.238,114.5,091099,14.7,W/GPS FIX
```
来自 Mic-E 单元的无效 GPS 数据。该单元将接收到的语句中的 `V` 字符解释为数据无效，并已去除 `$GPRMC` 头部。
