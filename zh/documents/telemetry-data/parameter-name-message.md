参数名称消息包含与五个模拟通道和 8 个数字通道关联的名称（N）。其格式如下：

**遥测参数名称消息数据**

注意不同的字节计数，其中包括所示位置的逗号。列表可以在任意字段处终止。

格式：
```
PARM.A1,N...[,N...][,N...][,N...][,N...][,N...][,N...][,N...][,N...][,N...][,N...][,N...][,N...][,N...]
```
字节数：5 1-7 1-7 1-6 1-6 1-5 1-6 1-5 1-4 1-4 1-4 1-3 1-3 1-3

**示例：**
```
:N0QBF-11V:PARM.Battery,Btemp,ATemp,Pres,Alt,Camra,Chut,Sun,10m,ATV
```
列表可以在任意字段之后终止。
