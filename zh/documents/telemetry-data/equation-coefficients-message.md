方程系数消息为五个模拟通道中的每一个包含三个系数（a、b 和 c）。

**遥测方程系数消息数据**

列表可以在任意字段处终止。值 = a × v² + b × v + c

格式：
```
EQNS.a,b,c,a,b,c,a,b,c,a,b,c,a,b,c
```
字节数：5 n n n n n n n n n n n n n n n

**示例：**
```
:N0QBF-11V:EQNS.0,5.2,0,0,.53,-32,3,4.39,49,-32,3,18,1,2,3
```
为了获得模拟通道的最终值，将这些系数代入方程：a × v² + b × v + c，其中 v 是原始接收的模拟值。

例如，上述信标示例中的模拟通道 A1 与电池电压相关，以百分之一伏为单位表示，a = 0，b = 5.2，c = 0。如果原始接收值 v 为 199，则电压计算如下：

```
voltage = 0 × 199² + 5.2 × 199 + 0
        = 1034.8 百分之一伏
        = 10.348 伏
```
