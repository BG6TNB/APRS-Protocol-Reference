# {{$frontmatter.order}} {{ $frontmatter.title }}

AX.25 信息字段可以包含遥测数据。APRS 数据类型标识符为 `T`。

报告序列号是一个 3 字符的值——通常是一个 3 位数字，或三个字母 MIC。对于 MIC 的情况，在第一个模拟数据值之前可能有也可能没有逗号。

有五个 8 位无符号模拟数据值（以 3 位十进制数表示，范围为 000–255），后跟一个 8 位数字数据值（以 8 个字节表示，每个字节包含 1 或 0）。

Kantronics KPC-3+ TNC 和 APRS 微接口模块（MIM）使用此格式。

**遥测报告格式**

| 字段 | 描述 |
|-------|-------------|
| T | 数据类型标识符 |
| #xxx, | 序列号（3 位数字或 MIC） |
| aaa, | 模拟值 1 |
| aaa, | 模拟值 2 |
| aaa, | 模拟值 3 |
| aaa, | 模拟值 4 |
| aaa, | 模拟值 5 |
| bbbbbbbb | 数字值（8 位，每位为 1 或 0） |
| Comment | 可选注释 |

字节数：1 5 4 4 4 4 4 8 n

**示例：**
```
T#005,199,000,255,073,123,01101001
T#MIC199,000,255,073,123,01101001
```
