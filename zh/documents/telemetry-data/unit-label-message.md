单位/标签消息指定模拟值的单位（U），以及与数字通道关联的标签（L）：

**遥测单位/标签消息数据**

注意不同的字节计数，其中包括所示位置的逗号。列表可以在任意字段处终止。

格式：
```
UNIT.A1,U...[,U...][,U...][,U...][,U...][,L...][,L...][,L...][,L...][,L...][,L...][,L...][,L...]
```
字节数：5 1-7 1-7 1-6 1-6 1-5 1-6 1-5 1-4 1-4 1-4 1-3 1-3 1-3

**示例：**
```
:N0QBF-11V:UNIT.v/100,deg.F,deg.F,Mbar,Kft,Click,OPEN,on,on,hi
```
列表可以在任意字段之后终止。
