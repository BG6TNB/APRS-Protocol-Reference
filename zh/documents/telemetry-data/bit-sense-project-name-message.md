位感知/项目名称消息包含两类信息：
- 一个 8 位的 1 和 0 模式，指定每个数字通道的感知，与对应的标签匹配。
- 与遥测站点关联的项目名称。

**遥测位感知/项目名称消息数据**

格式：
```
BITS.B1,B2,B3,B4,B5,B6,B7,B8^ 项目标题
```
字节数：5 1 1 1 1 1 1 1 1 0-23

**示例：**
```
:N0QBF-11V:BITS.10110000,N0QBF's Big Balloon
```
因此在上述消息示例中，如果数字通道 B1 为 1，这表示相机已拍照。如果通道 B2 为 0，表示降落伞已打开，以此类推。
