# {{$frontmatter.order}} {{ $frontmatter.title }}

一个固定长度的 7 字节字段可以跟在 APRS 位置数据之后。该字段是一个 APRS 数据扩展。扩展可以是以下之一：

- **CSE/SPD** 航向和速度（后面可以跟随一个额外的 8 字节，包含 DF 方位和编号/距离/质量参数）
- **DIR/SPD** 风向和风速
- **PHGphgd** 电台功率和有效天线高度/增益/方向性
- **RNGrrrr** 预先计算的无线电距离
- **DFSshgd** DF 信号强度和有效天线高度/增益
- **Tyy/Cxx** 区域对象描述符

7 字节的 CSE/SPD 数据扩展可用于表示车辆或 APRS 对象的航向和速度。

航向以度（001-360）表示，从正北顺时针方向。速度以节（knots）表示。斜杠 `/` 字符分隔两者。

例如：

```
088/036
```

表示航向 88 度，以 36 节的速度行驶。

如果航向和速度未知或不相关，可以将它们设置为 `000/000` 或 `.../...` 或 `VVVVVV/VVVVVV`。

::: tip 注意
在 DF 报告的特殊情况下，航向为 000 表示 DF 电台是固定的。如果航向非零，则电台是移动的。
:::
