# {{$frontmatter.order}} {{ $frontmatter.title }}

收到后，APRS 使用 p、h、g 和 d 代码计算可用的无线电距离（以英里为单位），以绘制表示电台周围本地无线电地平线的距离圈。无线电距离计算如下：

```
功率 = p^2
高于平均地形的高度 (haat) = 10 × 2^h
增益 = 10^(g/10)
距离 = √(2 × haat × √((功率/10) × (增益/2)))
```

因此，对于 `PHG5132`：

```
功率 = 5^2 = 25 瓦
haat = 10 × 2^1 = 20 英尺
增益 = 10^(3/10) = 1.995262
距离 = √(2 × 20 × √((25/10) × (1.995262/2)))
      ≈ 7.9 英里
```

由于最大增益方向为正东，APRS 将在电台周围绘制一个半径为 8 英里的距离圈，并向东偏移 2.7 英里（即 8 英里的三分之一）。

::: tip 注意
在没有任何 PHG 数据的情况下，假设电台使用 10 瓦功率驱动 3dB 全向天线，天线高度 20 英尺，形成以电台为中心、半径为 6 英里的距离圈。
:::
