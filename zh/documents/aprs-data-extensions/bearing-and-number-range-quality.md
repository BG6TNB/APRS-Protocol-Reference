# {{$frontmatter.order}} {{ $frontmatter.title }}

DF 报告在 CSE/SPD 数据扩展之后包含一个 8 字节字段 `/BRG/NRQ`，指定报告的航向、速度、方位和 NRQ（编号/距离/质量）值。NRQ 表示命中次数、近似距离和报告的质量。

例如，在：

```
...088/036/270/729...
```

航向 = 88 度，速度 = 36 节，方位 = 270 度，N = 7，R = 2，Q = 9。

如果 N 为 0，则 NRQ 值无意义。N 值从 1 到 8 给出了每个周期命中次数相对于时间段长度的指示——因此值为 8 意味着所有可能样本的 100% 获得了命中。N 值为 9 向其他用户表示报告是手动的。

N 值不被处理，而是作为来自自动 DF 单元的另一个指示器。

距离将线的长度限制为发送电台原始地图的比例。距离为 2^R，因此对于 R=4，距离将为 16 英里。

Q 是一个 0–9 范围内的单位数，提供了方位精度的指示：

**Q 方位精度**

| Q | 方位精度 | Q | 方位精度 |
| :---: | :--- | :---: | :--- |
| 0 | 无用 | 5 | < 16 度 |
| 1 | < 240 度 | 6 | < 8 度 |
| 2 | < 120 度 | 7 | < 4 度 |
| 3 | < 64 度 | 8 | < 2 度 |
| 4 | < 32 度 | 9 | < 1 度（最佳） |

如果航向和速度参数不合适，它们的值应为 `000/000` 或 `.../...` 或 `VVVVVV/VVVVVV`。
