# {{$frontmatter.order}} {{ $frontmatter.title }}

当一个电台传输不带时间戳的报告时，APRS 接收电台可以在内部记录接收时间（如需要）。此记录是接收电台对报告创建时间的理解。

另一方面，当一个电台传输带时间戳的报告时，该时间戳代表发射电台对报告创建时间的理解。

换句话说，不带时间戳发送的报告可被视为实时的"当前"报告（接收电台必须记录接收时间），而带时间戳发送的报告可能是实时的，也可能不是，甚至可能（非常）"旧"。

四个 APRS 数据类型标识符根据电台是否具有 APRS 消息能力来指定报告是否包含时间戳：

| 报告类型 | 无 APRS 消息能力 | 有 APRS 消息能力 |
| :--- | :---: | :---: |
| （当前/实时）不带时间戳的报告 | ! | = |
| （旧的/非实时）带时间戳的报告 | / | @ |

没有 APRS 消息能力的电台通常是独立的追踪器或数字中继器（digipeater）。不带时间戳报告的电台通常（但不一定）是固定电台。
