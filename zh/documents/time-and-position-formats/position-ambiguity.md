# {{$frontmatter.order}} {{ $frontmatter.title }}

在某些情况下（例如确切位置未知时），发射电台可能希望减少纬度和经度中的精确数字位数。此时，随着不精确程度的增加，纬度中的 mm 和 hh 数字可以逐步用空格字符替换。例如：

```
4903.5 N 表示纬度精确到十分之一分。
4903.  N 表示纬度精确到最近的分。
490 .  N 表示纬度精确到最近的 10 分。
49  .  N 表示纬度精确到最近的度。
```

纬度中指定的模糊程度会自动应用于经度——无需在经度中包含任何空格字符。

例如，坐标：

```
4903.  N/07201.75W-
```

表示精确到最近分的位置。也就是说，纬度和经度的百分之一分可以取 00–99 范围内的任何值。

因此，电台可能位于具有以下角坐标的边界框内的任何位置：

| 角点 | 纬度 | 经度 |
| :--- | :--- | :--- |
| 西北角 | 49 度 3.99 分 N | 72 度 1.99 分 W |
| 东北角 | 49 度 3.99 分 N | 72 度 1.00 分 W |
| 东南角 | 49 度 3.00 分 N | 72 度 1.00 分 W |
| 西南角 | 49 度 3.00 分 N | 72 度 1.99 分 W |
