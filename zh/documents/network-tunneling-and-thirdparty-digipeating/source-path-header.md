**带有源路径头的数据**

```
[源路径头] [数据类型标识符] [原始数据的其余部分]
字节数: n 1 n
```

源路径头可以采用两种格式之一，称为 "TNC-2" 格式和 "AEA" 格式（之所以这样命名，是因为当 TNC-2 或兼容 AEA 的 TNC 在终端 MONitor 模式下运行时，会自动生成这些格式的头）。

APRS 工作组已同意在未来的实现中向 "TNC-2" 格式标准化方向发展。

在大多数情况下，当 BBSMSGS 设置为 ON 时，AEA TNC 会以 "TNC-2" 格式生成源路径头。

**源路径头 — "TNC-2" 格式**

被收听的数字中继器呼号后跟有一个星号。

```
        0-8 个数字中继器
源呼号  >  目的呼号  ,  数字中继器呼号  :
    (-SSID)             (-SSID)               (-SSID)(*)

字节数: 1-9  1  1-9  0-81  1
```

示例：
```
WB4APR-14>APRS,RELAY*,WIDE:
```
（WIDE 数字中继器 "未使用"）

**源路径头 — "AEA" 格式**

被收听的源或数字中继器呼号后跟有一个星号。

```
        0-8 个数字中继器
源呼号  >  数字中继器呼号  >  目的呼号  :
    (-SSID)(*)          (-SSID)(*)              (-SSID)

字节数: 1-10  0-81  1  1-9  1
```

示例：
```
WB4APR-14>RELAY*>WIDE>APRS:
```
（WIDE 数字中继器 "未使用"）

在两种格式中，如果 SSID 为 –0，则可以省略 SSID。

在两种格式中，数据包从哪个数字中继器收听而来，该数字中继器的呼号用星号标记。（或者，仅对于 "AEA" 格式，如果数据包是直接从源台收听的，则星号将跟在源呼号之后）。

紧跟在被收听基站呼号之后的任何数字中继器都称为"未使用"。在构建第三方头（见下文）时，这些未使用的数字中继器将被剥离。
