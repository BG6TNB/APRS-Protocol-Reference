# {{$frontmatter.order}} {{ $frontmatter.title }}

当数据包从第三方网络传出后，接收网关基站会在本地 APRS 网络上发送之前，对其进行修改（通过插入 `}` 第三方数据类型标识符并修改源路径头）。

修改后的源路径头称为**第三方头（Third-Party Header）**。

**第三方格式**

```
}
```

**第三方头**

```
} [第三方头] [原始数据的其余部分]
字节数: 1 n n
```

与源路径头类似，第三方头可以采用两种格式之一："TNC-2" 或 "AEA" 格式。

**第三方头 — "TNC-2" 格式**

```
源路径头  ,  第三方网络标识符  ,  接收网关基站的呼号  *  :
（不含"未使用"       （"呼号"）                      （-SSID）
 数字中继器、* 或 :）

字节数: 3-99  1  1-9  1  1-9  1  1
```

示例：
```
WB4APR-14>APRS,RELAY,TCPIP,G9RXG*:
```

**第三方头 — "AEA" 格式**

```
源路径头  >  第三方网络标识符  >  接收网关基站的呼号  *  >  目的呼号  :
（不含"未使用"       （"呼号"）                       （-SSID）                                     来自源路径头
 数字中继器、                                                                                          （-SSID）
 目的、* 或 :）

字节数: 2-90  1-9  1  1-9  1  1  1-9  1
```

示例：
```
WB4APR-14>RELAY>TCPIP>G9RXG*>APRS:
```

在这两种情况下，原始源路径头中"未使用"的数字中继器呼号（即星号之后的那些数字中继器呼号）将被剥离。星号本身也会从源路径头中剥离。

然后插入两个额外的呼号：

- 第三方网络标识符（如 TCPIP）。这是一个虚拟的"呼号"，用于标识第三方网络的性质。
- 接收网关基站的呼号，后跟一个星号。
