# {{$frontmatter.order}} {{ $frontmatter.title }}

APRS 查询分为两种类型：一种是面向所有基站的通用查询，另一种是以消息格式定向到单个特定基站的查询。

查询始终以 `?` 开头，为一次性传输，不包含消息标识符，也不应被确认。同样，查询的响应也是一次性传输，同样不包含消息标识符，因此也不需要被确认。

每个查询包含一个查询类型（大写）。支持以下查询类型和预期响应：

| 查询类型 | 查询 | 响应 |
|----------|------|------|
| APRS  | 通用 — 所有基站查询 | 基站的位置和状态 |
| APRSD | 定向 — 查询单个基站直接听到的基站列表 | 直接听到的基站列表 |
| APRSH | 定向 — 查询单个基站是否听到了特定基站 | 以 APRS 对象形式返回被听到基站的位置，以及最近 8 小时的收听统计 |
| APRSM | 定向 — 查询单个基站未确认或未递送的待处理消息 | 查询方基站的所有待处理消息 |
| APRSO | 定向 — 查询单个基站的对象 | 基站的对象 |
| APRSP | 定向 — 查询单个基站的位置 | 基站的位置 |
| APRSS | 定向 — 查询单个基站的状态 | 基站的状态 |
| APRST 或 PING? | 定向 — 查询单个基站的路由追踪（即数据包被收听的路径） | 路由追踪 |
| IGATE | 通用 — 查询所有 Internet 网关 | IGate 基站能力 |
| WX | 通用 — 查询所有气象站 | 天气报告（如果天气报告中未包含位置，则还包含基站的位置） |

如果被查询的基站没有相关信息可以包含在响应中，则无需响应。被查询的基站应忽略任何它不认识的查询。
