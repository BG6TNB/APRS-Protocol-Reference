# {{$frontmatter.order}} {{ $frontmatter.title }}

路标对象/条目（使用符号 `\m`）显示为黄色方框，上面有 1–3 个字符的叠加层。叠加层通过在注释字段中将 1–3 个字符用大括号括起来指定。因此，带有 `{55}` 的路标将显示为上面有 55 字样的标志。

**示例：**
```
)I91V3N!4903.50N\07201.75Wm{55}
```
这最初是为了显示经过测速设备的交通速度而设计的，但也可以用于任何目的。

**实施建议：** 路标不应显示任何呼号或名称，为避免混乱，应仅在近距离显示。
