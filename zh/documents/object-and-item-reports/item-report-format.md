# {{$frontmatter.order}} {{ $frontmatter.title }}

条目报告具有可变长度的条目名称，长度为 3–9 个字符。名称可以由除 `!` 或 `_` 之外的任何可打印 ASCII 字符组成。

条目名称区分大小写。

`)` 是条目报告的 APRS 数据类型标识符，`!` 或 `_` 用于将条目名称与报告的其余部分分隔开：
- `!` 表示活跃条目。
- `_` 是条目"终止"字符。

位置可以采用纬度/经度或压缩纬度/经度格式。没有时间戳的规定。报告还可以包含扩展数据。

注释字段可以包含任何适当的 APRS 数据（参见第 5 章：AX.25 信息字段中的 APRS 数据中的注释字段部分）。

**条目报告格式 — 带有纬度/经度位置**

| 字段 | 描述 |
|-------|------|
| ) | 数据类型标识符 |
| 条目名称 | 3–9 个字符 |
| ! 或 _ | 活跃/终止指示器 |
| 纬度 | 纬度 |
| 符号表 ID | 符号表 ID |
| 经度 | 经度 |
| 符号代码 | 符号代码 |
| 区域对象 | 区域对象（可选） |
| 注释 | （带数据扩展最多 36 个字符，或不带 43 个字符） |

**示例：**
```
)AIDV#2!4903.50N/07201.75WA
)G/WB4APR! 53 VV.VVN\ 002 VV.VVWd
)AIDV#2_4903.50N/07201.75WA
```

**条目报告格式 — 带有压缩纬度/经度位置**

| 字段 | 描述 |
|-------|------|
| ) | 数据类型标识符 |
| 条目名称 | 3–9 个字符 |
| ! 或 _ | 活跃/终止指示器 |
| 压缩位置数据 | /YYYYXXXX$csT |
| 注释 | （最多 43 个字符） |

**示例：**
```
)MOBIL!\5L!!<*e7 9 VsT
```
