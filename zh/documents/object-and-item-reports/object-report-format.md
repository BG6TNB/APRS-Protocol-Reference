对象报告具有固定的 9 字符对象名称，可以由任何可打印的 ASCII 字符组成。

对象名称区分大小写。

`;` 是对象报告的 APRS 数据类型标识符，`*` 或 `_` 用于将对象名称与报告的其余部分分隔开：
- `*` 表示活跃对象。
- `_` 表示已终止对象。

位置可以采用纬度/经度或压缩纬度/经度格式，报告还可以包含扩展数据。对象始终具有时间戳。

注释字段可以包含任何适当的 APRS 数据（参见第 5 章：AX.25 信息字段中的 APRS 数据中的注释字段部分）。

**对象报告格式 — 带有纬度/经度位置**

| 字段 | 描述 |
|-------|------|
| ; | 数据类型标识符 |
| 对象名称 | 9 个字符 |
| * 或 _ | 活跃/终止指示器 |
| 时间 DHM/HMS | 时间戳 |
| 纬度 | 纬度 |
| 符号表 ID | 符号表 ID |
| 经度 | 经度 |
| 符号代码 | 符号代码 |
| 区域对象 | 区域对象（可选） |
| 注释 | （带数据扩展最多 36 个字符，或不带 43 个字符） |

**示例：**
```
;LEADERVVV*092345z4903.50N/07201.75W>088/036
;LEADERVVV_092345z4903.50N/07201.75W>088/036
```

**对象报告格式 — 带有压缩纬度/经度位置**

| 字段 | 描述 |
|-------|------|
| ; | 数据类型标识符 |
| 对象名称 | 9 个字符 |
| * 或 _ | 活跃/终止指示器 |
| 时间 DHM/HMS | 时间戳 |
| 压缩位置数据 | /YYYYXXXX$csT |
| 注释 | （最多 43 个字符） |

**示例：**
```
;LEADERVVV*092345z/5L!!<*e7>7P[
```
