# {{$frontmatter.order}} {{ $frontmatter.title }}

纬度/经度位置报告包含在 APRS AX.25 帧的信息字段中。

下图显示了这些报告的允许格式以及一些示例。灰色区域表示可选字段，阴影（黄色）字符是字面量 ASCII 字符。在所有情况下，符号代码之后最多有 43 个字符。

## 纬度/经度位置报告格式 — 不带时间戳

```
! 或 =   纬度   符号表标识符   经度   符号代码   评论（最多 43 字符）
字节：    1     8        1        9         1              0-43
```

示例
```
!4903.50N/07201.75W-Test 001234                               无时间戳，无 APRS 消息，带评论。
!4903.50N/07201.75W-Test /A=001234                             无时间戳，无 APRS 消息，海拔 = 1234 英尺。
!49VV.VVN/072VV.VVW-                                          无时间戳，无 APRS 消息，位置精确到最近的度。
TheNet VV X-1J4 VVVV (BFLD)!4903.50N/07201.75Wn               无时间戳，无 APRS 消息，带 X1J 节点头字符串。
```

## 纬度/经度位置报告格式 — 带时间戳

```
/ 或 @   时间        纬度   符号表标识符   经度   符号代码   评论（最多 43 字符）
         DHM/HMS
字节：    1      7     8        1         9          1              0-43
```

示例
```
/092345z4903.50N/07201.75W>Test1234   带时间戳，无 APRS 消息，祖鲁时间，带评论。
@092345/4903.50N/07201.75W>Test1234   带时间戳，有 APRS 消息，本地时间，带评论。
```

## 纬度/经度位置报告格式 — 带数据扩展（无时间戳）

数据扩展可以包含以下之一：航向/速度、功率/高度/增益/方向、无线电距离或 DF 信号强度。

```
! 或 =   纬度   符号表标识符   经度   符号代码   数据扩展   评论（最多 36 字符）
字节：    1     8        1        9         1              7               0-36
```

示例
```
=4903.50N/07201.75W#PHG5132                                  无时间戳，有 APRS 消息，带 PHG。
=4903.50N/07201.75W_225/000g000t050r000p001...h00b10138dU2k  天气报告。
```

## 纬度/经度位置报告格式 — 带数据扩展和时间戳

数据扩展可以包含以下之一：航向/速度、功率/高度/增益/方向、无线电距离或 DF 信号强度。

```
/ 或 @   时间        纬度   符号表标识符   经度   符号代码   数据扩展   评论（最多 36 字符）
         DHM/HMS
字节：    1      7     8        1         9          1              7               0-36
```

示例
```
@092345/4903.50N/07201.75W>088/036                  带时间戳，有 APRS 消息，本地时间，航向/速度。
@234517h4903.50N/07201.75W>PHG5132                  带时间戳，APRS 消息，时/分/秒时间，PHG。
@092345z4903.50N/07201.75W>RNG0050                  带时间戳，APRS 消息，祖鲁时间，无线电距离。
/234517h4903.50N/07201.75W>DFS2360                  带时间戳，时/分/秒时间，DF，无 APRS 消息。
@092345z4903.50N/07201.75W_090/000g000t066r000p000...dUII   天气报告。
```

## Maidenhead 定位器信标

```
[   网格定位器   ]   评论
字节： 1    4 或 6      1       n
```

示例
```
[IO91SX] 伦敦西北偏北 35 英里
[IO91]
```

## 原始 NMEA 位置报告格式

```
$   ^ ...,...,...,...,...,...,...
字节： 1           25-209
```

示例
```
$GPGGA,102705,5157.9762,N,00029.3256,W,1,04,2.0,75.7,M,47.6,M,,*62
$GPGLL,2554.459,N,08020.187,W,154027.281,A
$GPRMC,063909,A,3349.4302,N,11700.3721,W,43.022,89.3,291099,13.6,E*52
$GPVTG,318.7,T,,M,35.1,N,65.0,K*69
```
