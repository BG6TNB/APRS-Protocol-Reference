# {{$frontmatter.order}} {{ $frontmatter.title }}

DF 报告包含在 APRS AX.25 帧的信息字段中。方位和编号/距离/质量（BRG/NRQ）参数跟在数据扩展字段之后。

**注意：** 当报告包含 DF 符号时（即符号表标识符为 `/`，符号代码为 `\`），BRG/NRQ 参数才有意义。

**注意：** 如果 DF 电台是固定的，航向值为零。如果电台在移动，航向值非零。

## DF 报告格式 — 不带时间戳

数据扩展可以包含以下之一：航向/速度、功率/高度/增益/方向或无线电距离。

```
! 或 =   纬度   符号表标识符   经度   符号代码   数据扩展   /BRG/NRQ   评论（最多 28 字符）
                  (/)                   (\)              7                8              0-28
字节：    1     8        1        9         1              7                8             0-28
```

示例
```
=4903.50N/07201.75W\088/036/270/729    无时间戳，航向/速度/方位/NRQ，有 APRS 消息。DF 电台移动（CSE 非零）。
=4903.50N/07201.75W\ 000 /036/270/729  同一报告，DF 电台固定（CSE = 000）。
```

## DF 报告格式 — 带时间戳

数据扩展可以包含以下之一：航向/速度、功率/高度/增益/方向或无线电距离。

```
/ 或 @   时间        纬度   符号表标识符   经度   符号代码   数据扩展   /BRG/NRQ   评论（最多 28 字符）
         DHM/HMS           (/)                   (\)              7                8              0-28
字节：    1      7     8        1        9         1              7                8             0-28
```

示例
```
@092345z4903.50N/07201.75W\088/036/270/729   带时间戳，航向/速度/方位/NRQ，有 APRS 消息。
/092345z4903.50N/07201.75W\000/000/270/729   带时间戳，方位/NRQ，无航向/速度，无 APRS 消息。
```
