# {{ $frontmatter.title }}

本规范描述了开发符合 APRS 协议版本 1.0 的软件的总体要求。信息流从标准的 AX.25 UI 帧开始，随着对帧中每个字段用途的深入探索，逐步向下展开，细节愈发丰富。

本规范的一个关键特性是包含了大量典型 APRS 数据包及相关数学计算的详细示例。

以下是各章节概述：

**APRS 简介** - APRS 的简要背景及其主要功能摘要。

**APRS 设计哲学** - APRS 的基本原理，重点介绍其作为实时战术通信工具的用途、APRS 传输的时序以及通用数字中继（digipeating）的使用。

**APRS 与 AX.25** - AX.25 UI 帧结构的简要回顾，特别涉及 APRS 使用目的地址字段、源地址字段和信息字段的特殊方式。

**AX.25 目的地址和源地址字段中的 APRS 数据** - 通用 APRS 呼号及指定显示符号和 APRS 软件版本号的呼号详情。同时概述了 Mic-E 编码数据如何存储在目的地址字段中，以及源地址 SSID 如何指定显示图标。

**AX.25 信息字段中的 APRS 数据** - 存储在信息字段中的 APRS 数据主要组成部分的详情。包含 APRS 数据类型标识符表，以及信息字段可包含的所有不同数据类型的摘要。

**时间与位置格式** - 时间戳、纬度、经度、位置模糊度、Maidenhead 定位器、NMEA 数据和高度的格式信息。

**APRS 数据扩展** - 站点航向/速度、风速/风向、功率/高度/增益、预计算无线电范围、DF 信号强度和区域对象描述符等可选数据扩展的详情。

**位置与 DF 报告数据格式** - 这些报告格式的完整细节。

**压缩位置报告数据格式** - 站点位置和 APRS 数据扩展如何压缩为极短数据包的完整细节。

**Mic-E 数据格式** — Mic-E 将站点纬度/经度位置、高度、航向、速度、Mic-E 消息代码、遥测数据和 APRS 数字中继路径编码到 AX.25 目的地址和信息字段中的方式。

**对象与项目报告** - 如何设置 APRS 对象和项目的完整信息，以及区域对象（圆形、线形、椭圆形等）的编码详情。

**天气报告** - 独立（无位置）气象站天气报告及包含位置信息的报告的完整格式详情。同时包含风暴数据格式的详情。

**遥测数据** - MIM/KPC-3+ 遥测数据格式的描述，附有如何根据具体情况定制原始数据解读的辅助信息。

**消息、公告与通知** - 完整格式信息。

**站点能力、查询与响应** - 十种不同类型的查询及预期响应的详情。

**状态报告** - 通用状态消息的格式，以及使用状态报告包含流星散射波束航向/功率和 Maidenhead 定位器的特殊情况。

**网络隧道** - 使用源路径头允许 APRS 数据包通过不理解 AX.25 地址的第三方网络进行隧道传输，以及使用第三方数据类型标识符。

**用户自定义数据格式** - APRS 允许用户为特殊目的定义自己的数据格式。本章将介绍如何实现。

**其他数据包** - 关于 APRS 如何处理本规范未涵盖的任何其他数据包类型的通用说明。

**APRS 符号** — 如何在位置报告和通用 GPS 目的呼号中指定 APRS 符号和符号覆盖层。

**APRS 数据格式** - 一个附录，汇集了所有 APRS 数据格式以便于参考。

**APRS 符号表** — 主符号表和备用符号表中所有符号的完整列表。

**ASCII 码表** - 完整的 ASCII 编码，包括每个字符的十进制和十六进制代码（十进制代码用于压缩纬度/经度和高度计算），以及 AX.25 地址中位移 ASCII 字符的十六进制代码（用于 Mic-E 解码和通用空中数据包监测）。

**术语表** - 本规范中使用的众多 APRS 专用术语的便捷一站式参考。

**参考文献** - 与本规范相关的其他文档的指针。
