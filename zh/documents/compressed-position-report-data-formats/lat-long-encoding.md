# {{$frontmatter.order}} {{ $frontmatter.title }}

`YYYY` 和 `XXXX` 的值计算如下：

```
YYYY = 380926 x (90 – 纬度) [基数 91]
纬度为北纬时为正，南纬时为负，单位为度。
```

```
XXXX = 190463 x (180 + 经度) [基数 91]
经度为东经时为正，西经时为负，单位为度。
```

例如，对于西经 72° 45' 00"（即 -72.75 度）的经度，计算为 `190463 x (180 – 72.75) = 20427156`。由于采用基数 91，需要逐步将此值除以 91 的递减幂，以获得 X 的数值：

```
20427156 / 91^3 = 27 ，余数 80739
80739 / 91^2 = 9 ，余数 6210
6210 / 91 = 68 ，余数 22
```

为获得对应的 ASCII 字符，将每个值加上 33，得到 60（即 27+33）、42、101 和 55。从 ASCII 码表（附录 3）中，这对应于 `XXXX` 的 `<*e7`。
