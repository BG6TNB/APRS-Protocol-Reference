# {{$frontmatter.order}} {{ $frontmatter.title }}

如果 `T` 字节指示原始数据来自 GGA 语句（即 `T` 字节的位 4 和 3 为 `10`），则该语句包含一个以英尺为单位的海拔值。压缩后，压缩后的海拔数据被放置在 `cs` 字节中，使得：

```
海拔高度 = 1.002^cs 英尺
```

例如，如果接收到的 `cs` 字节为 `S]`，计算如下：

- 从每个字符的 ASCII 码中减去 33：
  - `c = 83 – 33 = 50`
  - `s = 93 – 33 = 60`
- 将 `c` 乘以 91 并加上 `s` 以获得 `cs`：
  - `cs = 50 x 91 + 60 = 4610`
- 然后海拔高度：
  - `海拔高度 = 1.002^4610 = 10004 英尺`
