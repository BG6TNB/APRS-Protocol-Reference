# {{$frontmatter.order}} {{ $frontmatter.title }}

`T` 字节紧跟在 `cs` 字节之后。`T` 字节包含多个位字段，用于显示 GPS 定位状态、位置数据的 NMEA 来源以及压缩的来源。

如果 `c` 字节为 ` `（空格），则 `T` 字节无意义。

**压缩类型（T）字节格式**

| 位 | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
|  | 未使用 | 未使用 | GPS 定位 | NMEA 来源 |  | 压缩来源 |  |  |

**GPS 定位（位 5）**

| 值 | 含义 |
| :---: | :--- |
| 0 | 旧的（上次） |
| 1 | 当前的 |

**NMEA 来源（位 4-3）**

| 值 | 含义 |
| :---: | :--- |
| 00 | 其他 |
| 01 | GLL |
| 10 | GGA |
| 11 | RMC |

**压缩来源（位 2-1-0）**

| 值 | 含义 |
| :---: | :--- |
| 000 | 已压缩 |
| 001 | TNC BText |
| 010 | 软件（DOS/Mac/Win/+SA） |
| 011 | [待定] |
| 100 | KPC3 |
| 101 | Pico |
| 110 | 其他跟踪器 [待定] |
| 111 | 数字中继器转换 |

例如，如果压缩位置来自 RMC 语句，定位是当前的，压缩由 APRSdos 软件执行，则 `T` 的二进制值为 `0 0 1 11 010`，等于十进制 58。将此值加 33 得到 `T` 字节的 ASCII 码（即 91），对应于 `[` 字符。

因此，使用前面所有示例中的数据，如果 RMC 语句包含（除其他参数外）以下数据：

```
纬度 = 北纬 49° 30' 00"
经度 = 西经 72° 45' 00"
速度 = 36.2 节
航向 = 88°
```

并且：

- 定位是当前的
- 压缩由 APRSdos 软件执行
- 显示符号为 "汽车"

则完整的 13 字符压缩位置字段发送如下：

```
/ YYYY XXXX $ csT
/ 5L!! <*e7 > 7P[
```
