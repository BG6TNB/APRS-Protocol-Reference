要解码压缩的经纬度，需要反向过程。也就是说，如果 `YYYY` 表示为 `y1 y2 y3 y4`，`XXXX` 表示为 `x1 x2 x3 x4`，则：

```
纬度 = 90 - ((y1 - 33) x 91^3 + (y2 - 33) x 91^2 + (y3 - 33) x 91 + y4 - 33) / 380926
```

```
经度 = -180 + ((x1 - 33) x 91^3 + (x2 - 33) x 91^2 + (x3 - 33) x 91 + x4 - 33) / 190463
```

例如，如果经度的压缩值为 `<*e7`（如上面计算的），则计算变为：

```
经度 = -180 + (27 x 91^3 + 9 x 91^2 + 68 x 91 + 22) / 190463
     = -180 + (20346417 + 74529 + 6188 + 22) / 190463
     = -180 + 107.25
     = -72.75 度
```
