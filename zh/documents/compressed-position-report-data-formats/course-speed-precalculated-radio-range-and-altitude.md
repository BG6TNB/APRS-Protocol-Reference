符号代码字符后面的两个 `cs` 字节可以包含压缩后的航向和速度，或压缩后的预计算射频范围，或电台的海拔高度。这两个字节采用基数 91 格式。

在特殊情况下，当 `c` = ` `（空格）时，表示没有航向、速度或范围数据，此时 `csT` 字节将被忽略。

## 航向/速度

如果 `c` 的 ASCII 码在 `!` 到 `z` 范围内（含）——对应十进制数值 0–89（即 ASCII 码减去 33 后）——则 `cs` 表示压缩后的航向/速度值：

```
航向 = c x 4
速度 = 1.08^s – 1
```

例如，如果 `cs` 字符为 `7P`，则 `c` 和 `s` 对应的值（ASCII 字符代码减去 33 后）分别为 22 和 47。将这些值代入上述公式：

```
航向 = 22 x 4 = 88 度
速度 = 1.08^47 – 1 = 36.2 节
```

## 预计算射频范围

如果 `c` = `{`，则 `cs` 表示压缩后的预计算射频范围值：

```
范围 = 2 x 1.08^s
```

例如，如果 `cs` 字节为 `{?`，`?` 的 ASCII 码为 63，因此 `s` 的值为 30（即 63-33）。因此：

```
范围 = 2 x 1.08^30
      ≈ 20 英里
```

因此，APRS 将在屏幕上的电台位置周围绘制一个半径为 20 英里的圆。
