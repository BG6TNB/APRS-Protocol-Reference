# {{$frontmatter.order}} {{ $frontmatter.title }}

前导符号表标识符（而非数字）的存在表明这是一个压缩位置报告，而非普通的经纬度报告。

压缩格式可以在任何出现 `...ddmm.hhN/dddmm.hhW$xxxxxxx...` 的地方替代经纬度位置格式。

除 `/` 和 `$` 外的所有字节均为基本 91 可打印 ASCII 字符（`!`..`{`）。通过从十进制 ASCII 字符代码中减去 33，将这些字符转换为数值。例如，`#` 的 ASCII 代码为 35，表示数值为 2（即 35-33）。
