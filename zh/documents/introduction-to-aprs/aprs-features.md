# {{$frontmatter.order}} {{ $frontmatter.title }}

APRS 可运行于大多数平台，包括 DOS、Windows 3.x、Windows 95/98、MacOS、Linux 和 Palm。这些平台上的大多数实现都支持 APRS 的主要功能：

- **地图** — APRS 电台位置可以实时绘制在地图上，覆盖范围从几百码到全球。报告航向和速度的电台会被航位推算到其当前位置。可用的叠加数据库包括 APRS 数字中继器的位置、美国国家气象局站点，甚至业余无线电商店。可以放大到地球上的任何一点。
- **气象站报告** — APRS 支持在屏幕上自动显示远程气象站信息。
- **DX 集群报告** — APRS 是 DX 集群用户的理想工具。连接到 DX 集群的少量 APRS 电台可以将 DX 电台信息中继给当地的许多其他电台，从而减少集群上的总分组负载。
- **互联网接入** — 互联网可以透明地用于在全球任何地方交叉连接本地无线电网络。可以通过 telnet 连接到互联网 APRS 服务器，实时查看来自世界各地的数百个电台。所有连接的用户都可以将本地听到的分组馈入 APRS 服务器系统，任何地方的所有人都可以看到它们。
- **消息** — 消息是带确认的双向消息。所有收到的消息在到达时会提醒用户，并在消息屏幕上保留直到被删除。
- **公告与通知** — 公告和通知面向所有人。公告每小时发送数次，持续数小时；通知发送频率较低，但可能持续数天。
- **固定电台跟踪** — 除了自动跟踪配备 GPS/LORAN 的移动电台外，APRS 还支持通过手动报告或网格正方形进行跟踪。
- **对象** — 任何用户都可以在自己的地图上放置一个 APRS 对象，该对象会在几秒钟内出现在所有其他电台的显示器上。这对于跟踪未配备跟踪器的资产或人员特别有用。只需一名分组操作员知道物体在哪里（例如通过监听语音流量），当他在屏幕上维护资产的位置和移动时，所有其他运行 APRS 的电台都会显示相同的信息。
