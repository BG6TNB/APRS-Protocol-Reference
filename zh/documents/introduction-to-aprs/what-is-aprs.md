# {{$frontmatter.order}} {{ $frontmatter.title }}

APRS 是 Automatic Position Reporting System（自动位置报告系统）的缩写，由 Bob Bruninga（WB4APR）设计，并于 1992 年在 TAPR/ARRL 数字通信会议上首次推出。

从根本上说，APRS 是一种分组通信协议，用于向网络中的所有用户实时传播直播数据。其最显著的特征是将分组无线电与全球定位系统（GPS）卫星网络相结合，使业余无线电爱好者能够在 PC 上的地图上自动显示无线电台和其他目标的位置。还支持与位置报告不直接相关的其他功能，例如气象站报告、测向和消息传递。

APRS 在以下几个方面与常规分组无线电不同：

- 它提供地图和其他数据显示，用于实时显示车辆/人员位置和气象报告。
- 它使用一对多协议进行所有通信，确保所有人都能立即获得更新。
- 它使用通用数字中继（generic digipeating），使用知名的呼号别名，因此无需预先了解网络拓扑。
- 它支持智能数字中继，通过呼号替换来减少网络泛洪。
- 使用 AX.25 UI 帧，它支持双向消息以及公告和通知的分发，实现文本信息的快速传播。
- 它支持与 Kenwood TH-D7 和 TM-D 电台的通信，这些电台内置了 TNC 和 APRS 固件。

传统分组无线电实际上仅适用于点对点传输大容量消息流量，并且历来难以应用于信息生命周期非常短的实时事件。APRS 将分组无线电转变为用于紧急情况和公共服务应用的实时战术通信和显示系统。

APRS 为所有电台提供普遍的连接性，同时避免了连接网络的复杂性、时间延迟和限制。它允许任意数量的电台像语音网络中的语音用户一样交换数据。任何有信息要贡献的电台只需发送信息，所有电台都会接收并记录。

APRS 认识到，在任何特殊事件或紧急情况下，最大的实时需求之一就是跟踪关键资产。马拉松领跑者在哪里？紧急车辆在哪里？全县各地的天气如何？电力线路在哪里中断？游行队伍的领头车在哪里？移动 ATV 摄像机在哪里？风暴在哪里？

为了解决这些问题，APRS 提供了功能齐全的自动车辆定位和状态报告系统。它可以在任何双向无线电系统上使用，包括业余无线电、海事频段和蜂窝电话。互联网上甚至还有一个国际实时 APRS 跟踪网络。
