# 附录 5: 术语表

```
海拔 1. 在 Mic-E 格式中，相对于平均海平面以下 10 米的高度（米）。
2. 在注释文本中，高于平均海平面的高度（英尺）。
通知 一条 APRS 消息，每小时重复数次，可能持续数天。
通知标识符 一个字母 A-Z，用于标识特定的通知。
天线高度 在 NMEA 语句中，天线相对于平均海平面的高度（米）。
（GPS NMEA 语句中的天线高度由于选择性可用性而剧烈波动，仅在应用 DGPS 校正时才可使用）。
APRS 自动位置报告系统。
APRS 数据 AX.25 信息字段中 APRS 数据类型标识符之后、APRS 数据扩展之前的数据。
APRS 数据扩展 APRS 数据的 7 字节扩展。数据扩展包括航向/速度、风向/风速、站点功率/天线有效高度/增益/方向性、预计算无线电范围、DF 信号强度/有效天线高度/增益、区域对象描述符中的一种。
APRS 数字中继路径 通过具有 RELAY、WIDE 及相关别名的中继器的数字中继路径。用于 Mic-E 压缩位置格式。
APRS 数据类型标识符 指定 AX.25 信息字段中包含何种 APRS 信息的单字节标识符。
区域对象 用户定义的图形对象（圆形、椭圆形、三角形、矩形和线形）。
ASCII 美国信息交换标准代码。符合 ANSI X3.4 (1968) 的 7 位字符代码 — 字符定义见附录 3。
AX.25 业余分组无线链路层协议。
91 进制 用于确保数值以可打印 ASCII 字符形式传输的数字进制。要获得与数值对应的字符串，将该值逐步除以 91 的递减幂，并在每一步将结果加上十进制 33。可打印字符范围为 !..{。用于压缩纬度/经度和高度计算。
公告 一条 APRS 消息，每小时重复数次，持续少量小时。通用公告不针对任何特定对象。组公告针对命名组（如 WX）。
公告标识符 一个数字 0-9，用于标识特定的公告。
目的地址字段 AX.25 目的地址字段，可包含 APRS 目的呼号或 Mic-E 编码数据。
DF 报告 包含 DF 方位角和距离的报告。
DGPS 差分 GPS。用于克服选择性可用性引起的误差。
DHM 7 字符时间戳：月份中的日期、小时、分钟、Zulu 或本地时间。
DHMz 7 字符时间戳：月份中的日期、小时、分钟，仅 Zulu 时间。
数字中继 转发 AX.25 数据包的站点。最多可指定 8 个数字中继的链路。
数字中继地址字段 包含 0–8 个数字中继呼号（或别名）的 AX.25 字段。
方向性 天线的优选方向。用于 PHG 数据扩展。
DX 集群 收集和发布用户 DX 活动报告的网络主机。
ECHO 一种通用 APRS 数字中继呼号别名，用于 HF 数字中继。
有效天线高度 天线高于本地地形（而非海平面）的高度。是天线在本地区域有效性的一阶指标。用于 PHG 数据扩展。
ERP 有效辐射功率。用于包含波束航向和功率数据的状态报告（通常用于流星散射）。
FCS 帧检查序列。AX.25 信息字段后面的 16 位序列，用于验证数据包的完整性。
GATE HF 和 VHF APRS 网络之间的网关。主要用于将长距离 HF APRS 业务中继到本地 VHF 网络。
GGA 语句 标准 NMEA 语句，包含接收站的纬度/经度位置和天线相对于平均海平面的高度，以及其他数据。
GLL 语句 标准 NMEA 语句，包含接收站的纬度/经度位置和其他数据。
GMT 格林威治标准时间（=UTC=Zulu）。
GPS 全球定位系统。由 24 颗卫星组成的全球网络，提供接收站的纬度/经度和天线高度。
GPSxyz 一种 APRS 目的呼号，指定来自主符号表或备用符号表的显示符号。备用符号表中的某些符号可以用数字或字母覆盖。用于无法在 AX.25 信息字段中指定符号的追踪器。
GPSCnn 一种 APRS 目的呼号，指定来自主符号表的显示符号。符号不可覆盖。用于无法在 AX.25 信息字段中指定符号的追踪器。
GPSEnn 一种 APRS 目的呼号，指定来自备用符号表的显示符号。符号不可覆盖。用于无法在 AX.25 信息字段中指定符号的追踪器。
HMS 1. 在 NMEA 语句中，6 字符时间戳：小时、分钟、秒 UTC。
2. 在 APRS 数据中，7 字符时间戳：小时、分钟、秒、Zulu 或本地。
ICQ 国际 CQ 聊天。
IGate VHF 和/或 HF APRS 网络与互联网之间的网关。
信息字段 包含 APRS 信息的 AX.25 信息字段。
项目 一种显示对象。
项目报告 包含 APRS 项目位置的报告。
已终止对象 APRS 用户已接管的对象。
节 国际海里每小时。
KPC-3 Kantronics 公司生产的终端节点控制器。
经度偏移 +100 度的经度偏移（用于 Mic-E 经度计算）。
LORAN 远程导航系统（GPS 的地面前身）。
Maidenhead 定位器 指定站点位置的 4 或 6 字符网格定位器。
MDHM 8 字节时间戳：月份、日期、小时、分钟（用于无位置气象站报告）。
消息 发送给特定站点的一行文本消息。
消息确认 对消息接收的可选确认。
消息组 用户定义的接收消息的组。
消息标识符 1–5 字符的消息标识符（通常为行号）。
Mic-E 最初为麦克风编码器，是一种将位置、航向和速度信息编码为极短数据包的单元，用于在释放麦克风 PTT 按钮时传输。Mic-E 编码算法现在也用于其他设备（如 PIC-E 和 Kenwood TH-D7/TM-D700 收音机）。
Mic-E 消息标识符 指定标准 Mic-E 消息或自定义消息代码的 3 位标识符（A/B/C）。
Mic-E 消息代码 指定标准或自定义 Mic-E 消息的 3 位代码。
MIM 微型接口模块。芯片上的完整遥测 TNC 发射器。
mph 英里每小时。
网络周期时间 获得 APRS 活动完整画面所需的时间（通常为 10、20 或 30 分钟，取决于经过的数字中继数量和本地条件）。除非在移动中或响应查询，否则站点不应更频繁地发送状态或位置信息。
NMEA 国家海洋电子协会（美国）。制定了 NMEA 0183 版本 2.0 规范，管理来自导航设备（如 GPS 和 LORAN 接收机）的接收语句格式。NMEA 语句格式的参考见附录 6。
NMEA（接收）语句 从导航设备（如 GPS 接收机）接收的符合 NMEA 0182 版本 2.0 规范的 ASCII 数据流。APRS 支持五种 NMEA 语句：GGA、GLL、RMC、VTG 和 WPT。
NRQ 数量/速率/质量。DF 方位角报告的置信度度量。
空位置 当实际位置未知或不确定时要报告的默认位置。空位置为北纬 0° 0' 0"，西经 0° 0' 0"。
NWS 国家气象局（美国）。
对象 通常不是站点的显示对象。例如，天气前锋或马拉松运动员。
对象报告 包含对象位置的报告，带有可选时间戳和 APRS 数据扩展。
PHG 指定功率、有效天线高度/增益/方向性的 APRS 数据扩展。
PIC 可编程接口控制器。
PIC-E Mic-E 麦克风编码器的 PIC 实现。
位置模糊度 APRS 位置信息精度的降低（通过将低阶纬度/经度数字替换为空格实现）。在确切位置未知时使用。
位置报告 包含纬度/经度位置的报告，可选带有时间戳和数据扩展。
预计算无线电范围 站点对全向无线电范围（英里）的估计。用于压缩纬度/经度格式。
查询 信息请求。查询可以面向一般站点或特定站点。
范围圆 从 PHG 数据计算的可用无线电范围（英里）。
RELAY 一种通用 APRS 数字中继呼号别名，用于具有有限本地覆盖的 VHF/UHF 数字中继。
响应 对查询的回复。
RMC 语句 标准 NMEA 语句，包含接收站的纬度/经度位置、航向和速度，以及其他数据。
RTCM 海事无线电技术委员会。RTCM SC104 数据格式规范描述了差分 GPS 数据校正的要求。
选择性可用性 故意的 GPS 位置抖动，在纬度、经度和天线高度方面引入显著的接收位置误差。使用差分 GPS 可以大大减少误差。
语句 见 NMEA（接收）语句。
路标 一种特殊的路标图标，将用户定义的变量信息（如速度限制或里程）显示为覆盖层。
Skywarn 美国国家气象局协调的天气观察员计划。
源地址字段 AX.25 源地址字段，包含发起站点的呼号。非零 SSID 指定显示符号。
源路径头 数据包进入第三方网络之前经过的数字中继路径。
SPCL 一种用于特殊站点的通用 APRS 目的呼号。
SSID 辅站标识符。范围为 0-15 的数字，作为 AX.25 地址的补充。如果源地址中的 SSID 非零，则指定一个显示符号。（用于站点无法在 AX.25 目的地址字段或信息字段中指定符号时）。
站点能力 作为对查询的回复发送的站点特征列表。
状态报告 包含站点状态信息（可选带有 Maidenhead 定位器）的报告。
流切换字符 通常用于切换 TNC 通道的字符。
符号 一种显示图标。由符号表标识符/符号代码对组成。一般地，/$ 表示主符号表中的符号，\$ 表示备用符号表中的符号。
符号代码 符号表中符号的代码。
符号表标识符 指定主符号表（/）或备用符号表（\）的 ASCII 代码。符号表标识符在 GPSCnn 和 GPSEnn 目的呼号中也是隐式的。
目标足迹 查询的目标区域。查询站点请求在指定纬度/经度位置的指定英里数范围内的站点响应。
TH-D7 Kenwood 生产的 VHF/UHF 手持收音机和 APRS 兼容 TNC 组合。
TM-D700 Kenwood 生产的 VHF/UHF 移动收音机和 APRS 兼容 TNC 组合。
第三方网络 不理解 AX.25 地址的非 APRS 网络（如互联网）。
第三方头 带有第三方网络标识符和接收网关呼号的路径头。
TNC 终端节点控制器。AX.25 分组组装/拆装器和调制解调器的组合。
追踪 一种询问数据包到指定站点所经过路线的 APRS 查询。
TRACE 一种通用数字中继呼号别名，用于执行呼号替换的数字中继。这些数字中继通过将自己的呼号插入到 RELAY、WIDE 或 TRACE 的位置来标识它们转发的数据包。
追踪器 由 GPS 接收机（获取当前地理位置）和无线电发射机（将位置发送给其他站点）组成的单元。
隧道 通过不理解 AX.25 寻址的第三方网络传输 APRS AX.25 业务。AX.25 地址作为数据（在源路径头中）通过隧道网络传输。
UI 帧 AX.25 非编号信息帧。APRS 仅使用 UI 帧——即以完全无连接（UNPROTO）模式运行。
UNPROTO 路径 到目的呼号的数字中继路径。
UTC 协调世界时（=Zulu=GMT）。
VTG 接收语句 标准 NMEA 语句，包含接收站的航向和速度。
WIDE 一种通用 APRS 数字中继呼号别名，用于具有广域覆盖的数字中继。
WIDEn-N 一种通用 APRS 数字中继呼号别名，用于具有广域覆盖的数字中继（N=0-7）。当数据包通过数字中继时，N 的值减 1，直到为零。数字中继会记录它转发的每个数据包（或其 FCS），如果它在过去 28 秒内已经转发过该数据包，则不会再次转发。
WPT 语句 标准 NMEA 语句，包含航点。
WX 天气。
Ziplan 一种通过串行 I/O 端口连接 PC 的廉价双绞线 LAN。设计用于应急情况。
Zulu UTC/GMT。
```

### 华氏 / 摄氏温度转换方程

```
F = ( C x 1.8 ) + 32
C = ( F – 32 ) x 5 / 9
```
