# {{$frontmatter.order}} {{ $frontmatter.title }}

APRS 是一个战术地理系统。为了最大化其操作有效性并最大程度减少不同系统操作员之间的混淆，用户需要有一种明确的方式向他人传达任何地图视图的"位置"和"大小"（或覆盖区域）。

APRS 的约定是通过参考中心点和范围来指定地理中心和适合地图视图的圆的近似半径（与宽高比无关）。圆的半径（以海里、法定英里或公里为单位）称为"范围标尺"。此约定为所有用户提供了一个简单的通用基础，用于通过任何通信媒介或程序向他人描述任何特定的地图视图。
