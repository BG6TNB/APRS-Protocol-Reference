# {{$frontmatter.order}} {{ $frontmatter.title }}

由于 APRS 分组是无差错的，但不保证交付，APRS 会冗余传输信息。为了确保新的或变化的数据能够快速交付，并通过减少旧数据的干扰来保持信道容量，APRS 应以比旧信息更高的频率传输新信息。

目前使用了几种算法来实现这一目标：

- **衰减算法（Decay Algorithm）** — 传输一个新分组一次，然后在 n 秒后再次传输。每次新传输时将 n 的值加倍。当 n 达到网络周期时间时，以该速率继续。除"加倍"之外的其他因素可能也适用，例如对于新消息行。
- **固定速率（Fixed Rate）** — 传输一个新分组一次，然后在 n 秒后再次传输。传输 x 次后停止。
- **听到即发（Message-on-Heard）** — 根据上述任一算法传输一个新分组。如果该分组仍然有效、尚未被确认且已达到网络周期时间，则接收方可能不在。但是，如果随后听到来自接收方的分组，则再次尝试传输该分组。
- **超时（Time-Out）** — 该术语用于描述一个时间段，超过该时间段后，如果没有听到来自某电台的任何分组，就可以合理地假设该电台已不存在或已停止工作。建议将 2 小时作为标称默认超时。此超时不用于任何传输算法，但在某些程序中可用于决定何时停止将电台显示为"活动"。注意，在 HF 上，信号时有时无，因此关于活动状态的判断可能需要更灵活。
