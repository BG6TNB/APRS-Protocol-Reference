# {{$frontmatter.order}} {{ $frontmatter.title }}

APRS 在现场的威力源于通用数字中继的使用，即分组在无需事先了解网络的情况下传播。自 1992 年 APRS 推出以来，已发展出六种强大的技术：

1. **RELAY** — 每个 VHF APRS TNC 都被假定具有 RELAY 别名，因此任何人都可以随时将其用作数字中继器。
2. **ECHO** — HF 电台使用 ECHO 作为 RELAY 的替代别名。（但请记住 HF 传播的特性，这有可能在广泛区域内造成干扰，移动电台应谨慎使用）。
3. **WIDE** — 每个高站点数字中继器都被假定具有 WIDE 别名，用于更长距离的通信。
4. **TRACE** — 每个使用呼号替换的高站点数字中继器都被假定具有 TRACE 别名。这些数字中继器通过插入自己的呼号来替代 RELAY、WIDE 或 TRACE，从而标识它们所中继的分组。
5. **WIDEn-N** — 支持 WIDEn-N 数字中继的数字中继器将中继任何"新的" WIDEn-N 分组，并将 SSID 减 1，直到 SSID 达到 –0。数字中继器保留分组的副本或校验和，并且通常在 28 秒内不会再次中继该分组。这大大减少了许多数字中继器相互处于无线电范围内的地区中多余的数字中继次数。
6. **GATE** — 该通用呼号用于 HF 转 VHF 网关数字中继器。任何通过 GATE 在 HF 上听到的分组都将在 VHF 上本地中继。这使本地网络能够关注全国和国际的整体情况。
