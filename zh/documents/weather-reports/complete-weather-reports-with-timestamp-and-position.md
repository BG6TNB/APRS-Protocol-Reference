# {{$frontmatter.order}} {{ $frontmatter.title }}

APRS 完整天气报告可以包含时间戳和位置信息，使用前面描述的任何合法的纬度/经度和压缩纬度/经度位置格式。APRS 对象也可以关联天气信息。

报告格式示例如下所示。请注意，在每种情况下，符号代码都是 `_`（下划线）。此外，7 字节的风向和风速数据扩展替代了无位置天气报告的 cccc 和 ssss 字段。

**完整天气报告格式 — 带有纬度/经度位置，无时间戳**
```
! or =
纬度
符号表 ID
经度
符号代码 _
风向/风速
天气数据
S（APRS 软件类型）
uuuu（气象站单位类型）
```
字节数：1 8 1 9 1 7 n 1 2-4

**示例：**
```
!4903.50N/07201.75W_220/004g005t077r000p000P000h50b09900wRSW
!4903.50N/07201.75W_220/004g005t077r000p000P000h50b.....wRSW
```

**完整天气报告格式 — 带有纬度/经度位置和时间戳**
```
/ or @
时间 DHM/HMS
纬度
符号表 ID
经度
符号代码 _
风向/风速
天气数据
S（APRS 软件类型）
uuuu（气象站单位类型）
```
字节数：1 7 8 1 9 1 7 n 1 2-4

**示例：**
```
@092345z4903.50N/07201.75W_220/004g005t-07r000p000P000h50b09900wRSW
```

**完整天气报告格式 — 带有压缩纬度/经度位置，无时间戳**
```
! or =
符号表 ID
压缩纬度 YYYY
压缩经度 XXXX
符号代码 _
压缩风向/风速
压缩类型 T
天气数据
S（APRS 软件类型）
uuuu（气象站单位类型）
```
字节数：1 1 4 4 1 2 1 n 1 2-4

**示例：**
```
=/5L!!<*e7> _7P[g005t077r000p000P000h50b09900wRSW
```

**完整天气报告格式 — 带有压缩纬度/经度位置，有时间戳**
```
/ or @
时间 DHM/HMS
符号表 ID
压缩纬度 YYYY
压缩经度 XXXX
符号代码 _
压缩风向/风速
压缩类型 T
天气数据
S（APRS 软件类型）
uuuu（气象站单位类型）
```
字节数：1 7 1 4 4 1 2 1 n 1 2-4

**示例：**
```
@092345z/5L!!<*e7 _7P[g005t077r000p000P000h50b09900wRSW
```

**完整天气报告格式 — 带有对象和纬度/经度位置**
```
;
对象名称
*
时间 DHM/HMS
纬度
符号表 ID
经度
符号代码 _
风向/风速
天气数据
S（APRS 软件类型）
uuuu（气象站单位类型）
```
字节数：1 9 1 7 8 1 9 1 7 n 1 2-4

**示例：**
```
;BRENDAVVV*4903.50N/07201.75W_220/004g005t077r000p000P000h50b09900wRSW
;BRENDAVVV*092345z4903.50N/07201.75W_220/004g005b0990
```
