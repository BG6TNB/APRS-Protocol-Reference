# {{$frontmatter.order}} {{ $frontmatter.title }}

APRS 是通过分组数据包报告天气状况的理想工具。APRS 支持 Peet Brothers、Ultimeter 和 Davis 家用气象站的串行数据传输。甚至可以仅使用 TNC 和无线电远程安装 Ultimeter 来报告和绘制天气状况。APRS 也非常适合 Skywarn 天气观察员计划。

APRS 支持三种类型的天气报告：
- 原始天气报告（Raw Weather Report）
- 无位置天气报告（Positionless Weather Report）
- 完整天气报告（Complete Weather Report）
