# {{$frontmatter.order}} {{ $frontmatter.title }}

天气报告可以包含一个 2–4 字符的代码 uuuu，用于表示气象站单位的类型。已分配以下代码：
- Dvs = Davis
- HKT = Heathkit
- PIC = PIC 设备
- RSW = Radio Shack
- U-II = 原始 Ultimeter U-II（自动模式）
- U2R = 原始 Ultimeter U-II（远程模式）
- U2k = Ultimeter 500/2000
- U2kr = 远程 Ultimeter 记录器
- U5 = Ultimeter 500
- Upkm = 远程 Ultimeter 分组模式

用户可以为不在此列表中的设备指定任何其他 2–4 字符的代码。
