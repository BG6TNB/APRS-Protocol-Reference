无位置天气报告中天气数据的格式因气象站单位类型而异，但通常包括以下部分或全部元素：

| 字段 | 描述 |
|------|------|
| cccc | 风向（度） |
| ssss | 持续一分钟风速（英里/小时） |
| gggg | 阵风（过去 5 分钟内的峰值风速，英里/小时） |
| tttt | 温度（°F，零下为 -01 到 -99） |
| rrrr | 过去一小时降雨量（百分之一英寸） |
| pppp | 过去 24 小时降雨量（百分之一英寸） |
| PPPP | 午夜以来降雨量（百分之一英寸） |
| hhh  | 湿度（%；00 = 100%） |
| bbbbbb | 气压（十分之一毫巴/十分之一百帕） |

一些气象站单位上可用的其他参数包括：
- L = 照度（瓦特每平方米）999 及以下。1000 及以上（L 会替代其中一个降雨量值的位置）。
- s = 过去 24 小时内的降雪量（英寸）。
- # = 原始雨量计数器

注意：天气报告必须至少包含 MDHM 日期/时间戳、风向、风速、阵风和温度，但其余参数可能顺序不同（或可能不存在）。

注意：当某项天气数据未知或不相关时，其值可以表示为一系列点或空格。例如，如果没有风速/风向/阵风传感器，风值可以表示为：
```
c...s...g... 或 c VVVVVV s VVVVVV g VVVVVV
```
例如，Jim 的雨量计可能产生这样的报告：
```
_10090556c...s...g...t...P012Jim
```
（日期/时间戳、风向/风速/阵风和温度参数必须包含在内，即使它们没有意义）。
