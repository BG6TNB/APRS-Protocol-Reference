APRS 报告可以包含与热带风暴、飓风和热带低气压相关的数据。数据格式如下：

| 字段 | 描述 |
|------|------|
| 方向/速度 | 风暴的方向和速度 |
| 风暴类型 /ST | TS（热带风暴）、HC（飓风）、TD（热带低气压） |
| 持续风速 /www | 持续风速（节） |
| 峰值阵风 ^GGG | 峰值风速（节） |
| 中心气压 /pppp | 中心气压（毫巴/百帕） |
| 飓风风圈半径 >RRR | 飓风风圈半径（海里） |
| 热带风暴风圈半径 &rrr | 热带风暴风圈半径（海里） |
| 全飓风级风圈半径 %ggg | "全飓风级"（即 50 节）风圈半径（海里，可选） |

风暴数据通常包含在对象报告中，但也可以包含在位置报告或条目报告中。

显示符号将是以下之一：

- `\@` 飓风/热带风暴（当前位置）
- `/@` 飓风（预测未来位置）

**示例：**
```
;BRENDAVVV*092345z4903.50N/07202.75W@088/036/HC/150^200/0980>090&030%040
;BRENDAVVV*100045z4905.50N/07201.75W@101/047/HC/104^123/0980>065&020%040
```
