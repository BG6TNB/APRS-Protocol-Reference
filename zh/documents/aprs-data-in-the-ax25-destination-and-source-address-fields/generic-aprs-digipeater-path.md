# {{$frontmatter.order}} {{ $frontmatter.title }}

所有数据包的目的地址字段中的 SSID 被编码以指定 APRS 数字中继器路径。

如果目的地址 SSID 为 –0，数据包遵循 AX.25 帧的数字中继器地址字段中包含的标准 AX.25 数字中继器（"VIA"）路径。

如果目的地址 SSID 为非零，数据包遵循 15 种通用 APRS 数字中继器路径之一。

目的地址中的 SSID 字段（即第 7 个地址字节）编码如下：

**目的地址 SSID 中的 APRS 数字中继器路径**

| SSID | 路径              | SSID | 路径              |
| ---- | ----------------- | ---- | ----------------- |
| -0   | 使用 VIA 路径     | -8   | 北路径            |
| -1   | WIDE1-1           | -9   | 南路径            |
| -2   | WIDE2-2           | -10  | 东路径            |
| -3   | WIDE3-3           | -11  | 西路径            |
| -4   | WIDE4-4           | -12  | 北路径 + WIDE     |
| -5   | WIDE5-5           | -13  | 南路径 + WIDE     |
| -6   | WIDE6-6           | -14  | 东路径 + WIDE     |
| -7   | WIDE7-7           | -15  | 西路径 + WIDE     |
