每个 APRS 数据包都包含一个 APRS 数据类型标识符（DTI）。它决定了信息字段中其余数据的格式，如下所示：

**APRS 数据类型标识符**

| 标识符 | 数据类型                                                                    |
| :---: | ---------------------------------------------------------------------------- |
| 0x1c  | 当前 Mic-E 数据（Rev 0 beta）                                              |
| 0x1d  | 旧版 Mic-E 数据（Rev 0 beta）                                                  |
| !     | 不带时间戳的位置（无 APRS 消息），或 Ultimeter 2000 气象站 |
| "     | *[未使用]*                                                                   |
| #     | Peet Bros U-II 气象站                                               |
| $     | 原始 GPS 数据或 Ultimeter 2000                                               |
| %     | Agrelo DFJr / MicroFinder                                                    |
| &     | [保留 — 地图要素]                                                     |
| '     | 旧版 Mic-E 数据（但 TM-D700 的当前数据）                                |
| (     | *[未使用]*                                                                   |
| )     | 项目                                                                         |
| *     | Peet Bros U-II 气象站                                               |
| +     | *[保留 — 带时间的避难所数据]*                                        |
| ,     | 无效数据或测试数据                                                    |
| -     | *[未使用]*                                                                   |
| .     | *[保留 — 空间天气]*                                                 |
| /     | 带时间戳的位置（无 APRS 消息）                                  |
| 0-9   | *[请勿使用]*                                                               |
| :     | 消息                                                                      |
| ;     | 对象                                                                       |
| <     | 电台能力                                                         |
| =     | 不带时间戳的位置（带 APRS 消息）                             |
| >     | 状态                                                                       |
| ?     | 查询                                                                        |
| @     | 带时间戳的位置（带 APRS 消息）                                |
| A–S   | *[请勿使用]*                                                               |
| T     | 遥测数据                                                               |
| U–Z   | *[请勿使用]*                                                               |
| [     | Maidenhead 网格定位器信标（已淘汰）                                    |
| \     | *[未使用]*                                                                   |
| ]     | *[未使用]*                                                                   |
| ^     | *[未使用]*                                                                   |
| _     | 天气报告（不带位置）                                            |
| '     | 当前 Mic-E 数据（TM-D700 中不使用）                                     |
| a–z   | *[请勿使用]*                                                               |
| {     | 用户定义的 APRS 数据包格式                                              |
| \|    | *[请勿使用 — TNC 流切换字符]*                                 |
| }     | 第三方流量                                                          |
| ~     | *[请勿使用 — TNC 流切换字符]*                                 |

**注意：** 数据类型标识符必须是信息字段中第一个字符的要求有一个例外——即不带时间戳的位置（由 **!** DTI 指示）。**!** 字符可以出现在信息字段中最多第 40 个字符位置的任何位置。这种可变性是支持 X1J TNC 数字中继器所必需的，这些中继器在字段开头有一串不可修改的文本。

**注意：** Kenwood TM-D700 电台使用 **'** DTI 表示当前 Mic-E 数据。该电台不使用 **'** DTI。
