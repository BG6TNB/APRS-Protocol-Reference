# {{$frontmatter.order}} {{ $frontmatter.title }}

两种 APRS 数据格式使用 base-91 表示法：压缩格式的纬度/经度坐标（参见第 9 章）和 Mic-E 格式的海拔（参见第 10 章）。

Base-91 数据被压缩为短字符串。所有字符均为可打印的 ASCII 字符，字符码范围为十进制 33–124（即 `!` 到 `|`）。

要计算给定数据值的 base-91 ASCII 字符串，将该值逐步除以递减的 91 的幂，直到余数小于 91。在每一步中，将除法过程的模数加上 33，以获得对应的 ASCII 字符码。

## 示例

对于数据值 12345678：

```
12345678 / 91^3 = 模数 16, 余数 288542
288542   / 91^2 = 模数 34, 余数 6988
6988     / 91^1 = 模数 76, 余数 72
```

因此，四个 ASCII 字符码分别为 49（即 16 + 33）、67（即 34 + 33）、109（即 76 + 33）和 105（即 72 + 33），对应 ASCII 字符串 `1Cmi`。
