# {{$frontmatter.order}} {{ $frontmatter.title }}

APRS 数据包不应包含多个符号。但是，可以想象（错误地）构造一个最多包含三个不同符号的数据包。

例如：

| 源地址 SSID | 目标地址 | 信息字段 |
|---|---|---|
| G3NRW-7 GPSMV |  | !0123.45N/01234.56Wj |
| 符号：小型飞机 | 符号：汽车 | 符号：吉普车 |

在这种情况下：

- 信息字段中的符号优先于任何其他符号。
- 如果信息字段中没有符号，目标地址中的符号优先于源地址 SSID 中的符号。
