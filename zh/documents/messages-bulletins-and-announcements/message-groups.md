# {{$frontmatter.order}} {{ $frontmatter.title }}

APRS 接收站点可以指定特殊的消息组，包含该站点将从中读取消息的呼号列表（除了发往自身的消息之外）。此类消息组由接收站点的用户在内部定义，用于过滤接收到的消息流量。

接收站点将读取所有收件人字段设置为 ALL、QST 或 CQ 的消息。

接收站点仅确认发往自身的消息，不确认任何发往组呼号的消息。

注意：接收站点将确认所有发往自身的消息，即使它在备用网络中操作（参见第 4 章：AX.25 目的地址和源地址字段中的 APRS 数据）。
