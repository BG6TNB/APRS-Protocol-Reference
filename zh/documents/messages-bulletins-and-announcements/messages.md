APRS 消息、公告和通告是包含自由格式文本字符串的数据包，旨在传达人类可读的信息。消息面向单个指定接收方接收，通常需要确认。公告和通告面向多个接收方接收，不需要确认。

**消息格式**
```
:收件人:消息文本{消息编号
```
- 收件人：9 个字符的字段（如有必要用空格填充）
- 消息文本：最多 67 个字符，除 |、~ 或 { 之外的任何可打印 ASCII 字符
- 消息编号：（可选）最多 5 个字母数字字符，不含空格，用于标识消息

没有消息标识符的消息不需要确认。带有消息标识符的消息应由收件人确认。发送站点将重复发送消息，直到收到确认、消息被取消或超时为止。

**示例：**
```
:WU2ZVVVVV:Testing
:WU2ZVVVVV:Testing{003
:EMAILVVVV:msproul@ap.org Test email
```
