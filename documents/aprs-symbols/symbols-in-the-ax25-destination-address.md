# {{$frontmatter.order}} {{ $frontmatter.title }}

Symbols can also be specified in the AX.25 Destination Address. This method is used when it is not possible to include the symbol in the Information field, such as with some trackers. The symbol is encoded using specific conventions in the destination address field.
