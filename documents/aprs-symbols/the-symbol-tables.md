There are two APRS Symbol Tables:

- **Primary Symbol Table**
- **Alternate Symbol Table**

The essential difference between the Primary and Alternate Symbol Tables is that some of the symbols in the Alternate Symbol Table can be overlaid with an alphanumeric character. For example, a "car" icon in the Alternate Symbol Table could be overlaid with the digit "3", to indicate it is car #3. Symbols capable of taking an overlay are marked as [with overlay]. None of the symbols in the Primary Symbol Table can be overlaid.

See Appendix 2 for a full listing of these tables.
