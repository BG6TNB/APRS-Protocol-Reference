# Fahrenheit / Celsius Temperature Conversion Equations

```text
F = ( C x 1.8 ) + 32
C = ( F – 32 ) x 5 / 9
```

In APRS, temperature is most commonly reported in degrees Fahrenheit, but some devices or packets may use Celsius. Always check the context or device documentation. Use the above equations to convert between Fahrenheit and Celsius as needed for accurate interpretation and display.
